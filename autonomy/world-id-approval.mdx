---
title: "World ID payment authorization"
description: "Authorize a payment when AgentBank returns approval_required without sharing a World ID proof with the agent."
---

When a payment returns `approval_required`, local clients use the returned
first-party AgentBank action URL. Hosted OAuth calls `show_payment_approval` to
display the embedded approval card and does not repeat the URL unless requested
or the card is unavailable.

<Steps>
  <Step title="Open the AgentBank action">
    Use the local action URL or hosted approval card. Sign in as the payment
    owner; AgentBank reveals the World ID request only after authentication.
  </Step>
  <Step title="Authorize in World App">
    Complete the payment-specific authorization before its expiry.
  </Step>
  <Step title="Resume the same payment">
    The agent polls `get_payment` and continues when it reaches
    `approval_ready`.
  </Step>
</Steps>

Never paste, print, reconstruct, or send a World ID proof or raw verification
request in chat. A World ID badge check does not replace payment authorization.
