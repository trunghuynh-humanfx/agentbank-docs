---
title: "List payments"
description: "List B2B payments owned by the signed merchant."
---

```text
GET /v1/partner/payments
```

**Authentication:** signed Partner API request, including the query string in
the canonical path.

## Query parameters

| Parameter       | Required | Description                                                            |
| --------------- | -------- | ---------------------------------------------------------------------- |
| `status`        | No       | Comma-separated raw payment statuses. Cannot be combined with `state`. |
| `state`         | No       | One of `all`, `active`, `completed`, `pending`, or `failed`.           |
| `created_after` | No       | ISO-8601 timestamp lower bound.                                        |
| `limit`         | No       | Page size from 1 to 100; default 50.                                   |
| `offset`        | No       | Zero-based page offset; default 0.                                     |

```text
GET /v1/partner/payments?state=active&limit=20&offset=0
```

## Response

```json
{
  "total": 1,
  "payments": [
    {
      "payment_id": "pay_...",
      "merchant_payment_reference": "invoice-1042",
      "status": "funding_required",
      "terminal": false,
      "successful": false,
      "source": {"asset":{"type":"crypto","ticker":"USDC","chain":"worldchain"},"amount":"6"},
      "destination": {"asset":{"type":"fiat","symbol":"BRL"}},
      "created_at": "2026-08-19T08:00:00.000Z",
      "updated_at": "2026-08-19T08:00:00.000Z"
    }
  ]
}
```

The list contains only payments owned by the authenticating merchant and omits
the timeline. Read a specific payment for funding instructions and history.
