---
title: "Update webhook"
description: "Replace the URL of one active merchant webhook endpoint."
---

```text
PATCH /v1/merchant/webhooks/:endpointId
```

**Authentication:** `Authorization: Bearer <portal_jwt>`.

## Path parameters

| Parameter    | Required | Description                                  |
| ------------ | -------- | -------------------------------------------- |
| `endpointId` | Yes      | Active merchant-owned `mwe_...` endpoint ID. |

## Request body

```json
{
  "url": "https://merchant.example/webhooks/agentbank-v2"
}
```

## Response

```json
{
  "endpoint_id": "mwe_...",
  "url": "https://merchant.example/webhooks/agentbank-v2",
  "status": "active",
  "signing_scheme": "hmac_sha256_v1",
  "created_at": "2026-08-19T08:00:00.000Z",
  "updated_at": "2026-08-19T08:10:00.000Z",
  "disabled_at": null
}
```

Only the URL changes. The signing secret and endpoint identity remain the same.
A disabled endpoint cannot be updated.
