---
title: "Get webhook"
description: "Read metadata for one merchant-owned webhook endpoint."
---

```text
GET /v1/merchant/webhooks/:endpointId
```

**Authentication:** `Authorization: Bearer <portal_jwt>`.

## Path parameters

| Parameter    | Required | Description                           |
| ------------ | -------- | ------------------------------------- |
| `endpointId` | Yes      | Merchant-owned `mwe_...` endpoint ID. |

## Response

```json
{
  "endpoint_id": "mwe_...",
  "url": "https://merchant.example/webhooks/agentbank",
  "status": "active",
  "signing_scheme": "hmac_sha256_v1",
  "created_at": "2026-08-19T08:00:00.000Z",
  "updated_at": "2026-08-19T08:00:00.000Z",
  "disabled_at": null
}
```

The endpoint's signing secret is intentionally absent. If it was lost, create
a replacement endpoint and change the receiver to its new secret.
