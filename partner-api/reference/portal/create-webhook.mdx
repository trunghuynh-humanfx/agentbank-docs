---
title: "Create webhook"
description: "Register a merchant webhook endpoint and receive its one-time HMAC signing secret."
---

```text
POST /v1/merchant/webhooks
```

**Authentication:** `Authorization: Bearer <portal_jwt>`.

## Request body

```json
{
  "url": "https://merchant.example/webhooks/agentbank"
}
```

`url` must be an absolute URL and can be up to 2,000 characters. It must be
publicly reachable over HTTPS in production.

## Response

```json
{
  "endpoint_id": "mwe_...",
  "url": "https://merchant.example/webhooks/agentbank",
  "status": "active",
  "signing_scheme": "hmac_sha256_v1",
  "created_at": "2026-08-19T08:00:00.000Z",
  "updated_at": "2026-08-19T08:00:00.000Z",
  "disabled_at": null,
  "signing_secret": "shown-once-only"
}
```

Persist `signing_secret` before continuing. It is returned only by this
endpoint and cannot be recovered, read, or changed later. See
[Portal and webhooks](../../portal-and-webhooks) for delivery verification.
