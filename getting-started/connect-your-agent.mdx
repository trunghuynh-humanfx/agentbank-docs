---
title: "1. Connect your agent"
description: "Configure AgentBank MCP for Codex, Claude Code, Claude Desktop, OpenClaw, or Hermes."
---

AgentBank uses a local stdio MCP server for personal agents. The published
package defaults to production, so normal production setup does not need
endpoint overrides. See [Environment](/getting-started/environment) for the
staging override.

<Tabs>
  <Tab title="Codex">
    ```bash
    codex mcp add agentbank -- npx -y agent-bank-mcp@latest
    ```
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add agentbank -- npx -y agent-bank-mcp@latest
    ```
  </Tab>
  <Tab title="Claude Desktop">
    On macOS, edit:

    ```text
    ~/Library/Application Support/Claude/claude_desktop_config.json
    ```

    ```json
    {
      "mcpServers": {
        "agentbank": {
          "command": "npx",
          "args": ["-y", "agent-bank-mcp@latest"]
        }
      }
    }
    ```

    Preserve other `mcpServers` entries, fully quit Claude Desktop, and reopen it.
  </Tab>
  <Tab title="OpenClaw">
    Add the server under `mcp.servers` in `~/.openclaw/openclaw.json`:

    ```json5
    {
      mcp: {
        servers: {
          agentbank: {
            command: "npx",
            args: ["-y", "agent-bank-mcp@latest"],
          },
        },
      },
    }
    ```

    Then verify:

    ```bash
    openclaw mcp doctor agentbank --probe
    ```
  </Tab>
  <Tab title="Hermes">
    ```bash
    hermes mcp add agentbank --command npx --args -y agent-bank-mcp@latest
    ```

    Run `/reload-mcp`. Hermes registers tools using names such as
    `mcp_agentbank_whoami`.
  </Tab>
</Tabs>

## Verify the connection

Restart or reload the client, then ask:

```text
Check whether the AgentBank MCP exposes whoami, get_instructions, and begin_agent_onboarding. Do not start a payment.
```

If the tools are missing, check Node.js, `npx`, configuration syntax, and then
restart or reload the client.
