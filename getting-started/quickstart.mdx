title: "Quickstart"
description: "Choose a connection, authorize AgentBank, install the skill when needed, and verify readiness."
---

Using ChatGPT or Claude's remote connectors? Follow the
[Remote MCP setup](/getting-started/hosted-oauth) to connect with OAuth.

<Steps>
  <Step title="Choose an environment">
    Use [staging](/getting-started/environment#staging) for mock tokens or
    [production](/getting-started/environment#production) for live routes.
  </Step>
  <Step title="Choose a connection type">
    Use [local stdio](/getting-started/connect-your-agent) for an agent running
    on your device, or [hosted OAuth](/getting-started/hosted-oauth) in a
    supported OAuth-capable host.
  </Step>
  <Step title="Install the AgentBank Pay skill">
    Install from `theagentbank/skills` or load the canonical skill URL.
  </Step>
  <Step title="Check readiness">
    Ask your agent:

    ```text
    Check my AgentBank connection, account readiness, and wallet. Do not create a payment.
    ```
  </Step>
  <Step title="Complete authorization">
    A local installation with missing credentials returns **Connect to your
    AgentBank Account**. A hosted connection uses its OAuth authorization flow.
  </Step>
  <Step title="Verify the account">
    Your agent calls `whoami`, checks scopes, and reads `list_wallets`. Local
    installations also check account and installation readiness.
  </Step>
</Steps>
