---
title: "Revoke a connected agent"
description: "Disconnect a lost, compromised, or no-longer-needed AgentBank agent installation."
---

Use `revoke_agent` when a device or connected agent is compromised, lost, or no
longer authorized.

Before calling it, explain that revocation:

- invalidates the installation credential;
- invalidates its sessions and wallet authorization;
- clears local AgentBank credentials for that profile;
- prevents further use by that connected agent.

The tool requires `confirm=true` after explicit user confirmation. After
revocation, reconnect through a new browser authorization flow if needed.
