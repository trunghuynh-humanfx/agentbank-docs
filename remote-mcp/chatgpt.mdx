This setup uses ChatGPT's custom MCP connection. Developer mode availability
depends on your account and workspace policy.

<Steps>
  <Step title="Enable developer mode">
    Open **Settings → Security and login** in ChatGPT and turn on
    **Developer mode**.
  </Step>
  <Step title="Add AgentBank">
    Open [ChatGPT Plugins](https://chatgpt.com/plugins), select the plus button,
    and enter **AgentBank** as the name. Add a short description such as
    “Collect payments, exchange currencies, and send money with AgentBank.”

    Under **Connection**, enter:

    ```text
    https://plugin.agentbank.world/mcp
    ```

    Create the connection and review the available tools.
  </Step>
  <Step title="Sign in">
    Complete AgentBank's browser sign-in when prompted. Choose your account
    and review the requested permissions.
  </Step>
  <Step title="Start a conversation">
    Start a new chat and add AgentBank from the tools menu. Ask:

    ```text
    Check my AgentBank account and wallet. Tell me if any setup is still needed.
    ```

    Confirm that the connected account is yours.
  </Step>
</Steps>

Continue with [Your first payment](/getting-started/first-payment) or
[Example prompts](/ai-guides/conversation-patterns).

<Accordion title="Connection troubleshooting">
  If developer mode is unavailable, check your account or workspace policy.
  Verify the full server URL, including `/mcp`, and ensure AgentBank is
  enabled in the current conversation.

  If the available tools have changed, open the connection in ChatGPT Plugins,
  select **Refresh**, and start a new conversation. For a missing payment card,
  ask the assistant to reopen it.
</Accordion>

See OpenAI's [connection guide](https://developers.openai.com/plugins/deploy/connect-chatgpt)
for the current interface and access requirements.
