---
title: "Troubleshooting"
description: "Find the next step for connection, verification, and payment problems."
---

<AccordionGroup>
  <Accordion title="My assistant cannot find AgentBank">
    In ChatGPT or Claude, check that AgentBank is connected and enabled in the
    current conversation. For a local agent, check its configuration and
    restart or reload the client. Follow your
    [connection guide](/getting-started/quickstart).
  </Accordion>
  <Accordion title="Sign-in or authorization is still pending">
    Finish the AgentBank browser flow, then return to the same conversation.
    Ask the agent to check the existing connection before starting setup again.
    Never paste sign-in tokens into chat.
  </Accordion>
  <Accordion title="Identity verification is not ready">
    Complete the requested browser checks and wait for the result.
    A submitted identity check may still need review for the selected currency.
    See [Identity verification](/autonomy/kyc).
  </Accordion>
  <Accordion title="The recipient details are incomplete">
    Provide the missing details requested by the agent and review the recipient
    before confirming. For a screenshot containing only text, paste the bank
    details as text; QR images must contain a readable QR code.
  </Accordion>
  <Accordion title="The quote changed or expired">
    Ask for an updated quote and review the new amounts and fees before
    confirming. If a payment already exists, ask the agent to check it first.
  </Accordion>
  <Accordion title="I paid, but the payment is still pending">
    Ask the agent to track the existing payment. Do not pay again just because
    payment detection or delivery is pending. See
    [Payment status and tracking](/payments/track-payments).
  </Accordion>
  <Accordion title="I cannot see the approval or funding card">
    Ask the assistant to reopen the card for the existing payment or provide
    the available action link. See [Payment cards](/payments/hosted-payment-cards).
  </Accordion>
  <Accordion title="The payment failed or its approval expired">
    Ask the agent to check whether funds moved and what recovery is available
    before creating another payment. See [Recover a payment](/payments/recover-failures).
    If you already paid, contact support before sending more money.
  </Accordion>
</AccordionGroup>

For local credential errors and tool-level recovery, see
[MCP troubleshooting](/reference/troubleshooting).
