---
title: "list_payments"
description: "List durable payments scoped to the current local installation or hosted OAuth connection."
---

**Authentication:** `settlement:prepare`  
**Mutates state:** No

```json
{
  "status": ["completed"],
  "created_after": "2026-07-26T00:00:00Z",
  "limit": 50,
  "offset": 0
}
```

Returns durable Core records visible to the current local installation or
hosted OAuth connection. Results survive restarts. Pagination uses `offset` and
`limit`.
