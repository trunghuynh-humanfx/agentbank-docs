---
title: "get_spending_grant"
description: "Inspect one selected hosted spending limit without displaying its card."
---

**Surface:** Hosted OAuth  
**Mutates state:** No

```json
{ "grant_id": "grant_..." }
```

Use only when the spending-limit list lacks detail needed for a selected candidate. To
display a pending spending limit for activation, call `show_spending_grant` instead.
