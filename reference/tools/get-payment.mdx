---
title: "get_payment"
description: "Read the authoritative durable aggregate for one payment."
---

**Authentication:** `settlement:prepare`  
**Mutates state:** No

```json
{ "payment_id": "pay_...", "include_debug": false }
```

`include_debug=true` requires `debug:read` or wildcard scope.

Returns status, terminal and success flags, summary, retryability, canonical
source, redacted destination, amount mode, routing, authorization, current
instruction, `funds_moved`, failure, next action, public step summaries, and
timestamps.

Public statuses are `approval_required`, `approval_ready`, `funding_required`,
`funding_detecting`, `processing`, `need_review`,
`recipient_correction_required`, `completed`, `cancelled`, `expired`,
`funding_timeout`, and `failed`.

This is the authoritative payment state. Internal orchestration identifiers and
sensitive recipient fields are omitted.

On hosted OAuth this read is card-free. Reopen a missed pre-funding card with
`get_payment_instruction`; after funds move, display `show_payment_progress`.
