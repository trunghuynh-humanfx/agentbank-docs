---
title: "list_wallets"
description: "List the public AgentBank wallet bound to the current connection."
---

**Authentication:** `agent_wallet:use`  
**Mutates state:** No

```json
{}
```

Local stdio returns the wallet bound during browser onboarding. Hosted OAuth
returns the owner's shared Privy wallet for that connection. Both surfaces
expose public wallet identifiers and addresses only.

Use the returned wallet rather than asking the user to paste or infer an
address.
